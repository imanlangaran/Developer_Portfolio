# مستندات پروژه نمونه (پروژه خصوصی)

> این فایل به عنوان یک نمونه برای نحوه ساختاردهی و نگارش مستندات پروژه‌های خصوصی در این پورتفولیو تهیه شده است.

---

## معرفی

این پوشه (`public/docs/example-project/`) به عنوان یک الگوی کامل برای ثبت مستندات **پروژه‌های خصوصی** (مانند پروژه‌های سازمانی، محصولات تجاری و کدهای محرمانه کارفرما) که سورس‌کد آن‌ها به صورت عمومی در گیت‌هاب قرار ندارد، استفاده می‌شود.

هنگامی که یک پروژه با مشخصه `type: "private"` در فایل `src/utils/data.js` تعریف می‌شود، بخش جزئیات پروژه در پورتفولیو مستندات مربوطه را مستقیماً از پوشه محلی `public/docs/<slug>/` بارگذاری و نمایش می‌دهد.

---

## ساختار فایل‌ها و پوشه‌ها

برای تعریف مستندات یک پروژه خصوصی، کافی است پوشه‌ای متناسب با شناسه `slug` پروژه در مسیر `public/docs/` ایجاد کنید:

```
public/
└── docs/
    └── example-project/
        ├── README.md          # مستندات به زبان انگلیسی (فایل پیش‌فرض و fallback)
        ├── README-fa.md       # مستندات به زبان فارسی (بارگذاری هنگام انتخاب زبان fa)
        └── preview.png        # تصاویر، دیاگرام‌های معماری و اسکرین‌شات‌ها
```

---

## پیکربندی در فایل `src/utils/data.js`

یک نمونه از شیء پیکربندی در آرایه `PROJECTS`:

```javascript
{
  id: 10,
  title: "Enterprise Dashboard",
  description: "داشبورد سازمانی پیشرفته برای مدیریت یکپارچه داده‌ها و فرآیندها.",
  image: false, // یا وارد کردن تصویر از src/assets/images/
  tags: ["React", "TypeScript", "Tailwind CSS", "Node.js", "PostgreSQL"],
  type: "private",
  slug: "example-project", // متناظر با پوشه public/docs/example-project/
  liveUrl: "https://demo.example.com", // آدرس اختیاری نسخه دمو
  featured: true,
  category: "Full Stack",
}
```

### مشخصات و تنظیمات

| ویژگی | نوع | توضیحات |
| :--- | :--- | :--- |
| `type` | `"private"` | پروژه را به عنوان خصوصی علامت‌گذاری می‌کند و دکمه مخزن گیت‌هاب را در رابط کاربری پنهان می‌سازد. |
| `slug` | `string` | نام پوشه در مسیر `public/docs/` که مستندات پروژه در آن قرار دارد. |
| `readme` | `string` | *(اختیاری)* نام مستعار برای `slug`. در صورت وجود هر دو، `readme` اولویت دارد. |
| `githubUrl` | `string` | *(اختیاری / غیرضروری)* برای پروژه‌های خصوصی نیازی به مقداردهی ندارد. |
| `liveUrl` | `string` | *(اختیاری)* دکمه **پیش‌نمایش آنلاین** (Live Preview) را نمایش می‌دهد. |

## درج تصاویر و فایل‌های رسانه‌ای

می‌توانید اسکرین‌شات‌ها و دیاگرام‌های معماری را مستقیماً درون پوشه `public/docs/<slug>/` قرار دهید و با مسیرهای نسبی به آن‌ها ارجاع دهید:

```markdown
![دیاگرام معماری](./architecture.png)
```

سیستم رندر مارک‌داون به صورت خودکار آدرس‌های نسبی را با مسیر پوشه جاری پروژه تنظیم می‌کند.

---

## پشتیبانی از چندزبانه بودن (i18n)

بخش نمایش مستندات به صورت هوشمند زبان فعال کاربر را تشخیص می‌دهد:

- **انگلیسی (`en`)**: فایل `README.md` فراخوانی می‌شود.
- **فارسی (`fa`)**: فایل `README-fa.md` فراخوانی می‌شود.
- **جایگزین خودکار (Fallback)**: در صورتی که فایل زبان فارسی موجود نباشد، سامانه بدون خطا فایل پیش‌فرض `README.md` را نمایش می‌دهد.

## بخش نمونه پروژه

### معماری و تکنولوژی‌ها

- **فرانت‌اند**: React 19، Tailwind CSS، Lucide Icons
- **بک‌اند**: Node.js، Express، Redis
- **پایگاه داده**: PostgreSQL به همراه Drizzle ORM
- **زیرساخت**: Docker، Nginx و پایپ‌لاین CI/CD

### امکانات شاخص

۱. **مدیریت سطوح دسترسی (RBAC)**: تفکیک دقیق دسترسی کاربران، مدیران و ناظران سیستم.
۲. **مانیتورینگ آنی**: نمایش نمودارهای زنده با تاخیر میلی‌ثانیه‌ای از طریق وب‌سوکت.
۳. **خروجی گزارش‌ها**: تولید خودکار گزارش‌های تحلیلی با فرمت‌های PDF و CSV.
۴. **لاگ جامع عملیات**: ثبت غیرقابل تغییر رویدادها و فعالیت‌های حساس مدیریتی.

# TradeAgent — ایجنت تحلیل بازار با هوش مصنوعی

> یک ایجنت معامله‌گر فقط‌خواندنی ساختم: داده‌های بازار را همگام می‌کند، اندیکاتورها را در کد محاسبه می‌کند و از مدل زبانی می‌خواهد ایده‌های ورود/خروج/ریسک پیشنهاد دهد — هرگز خودش معامله‌ای اجرا نمی‌کند.

## چه چیزی ساختم

- **هسته استراتژی‌محور** — هر استراتژی یک پوشه با دو فایل است: `strategy.md` (قواعد) و `config.py` (نمادها، تایم‌فریم‌ها، اندیکاتورها، پارامترهای ریسک). چیزی در هسته hardcode نشده، پس اضافه کردن یک استراتژی یعنی اضافه کردن فایل، نه دست‌کاری موتور.
- **داده بازار از چند منبع** — یک رابط `MarketDataProvider` با چهار بک‌اند: CCXT، یاهو فایننس (`yfinance`)، متاتریدر ۵ و یک بک‌اند فایل‌محور برای پخش آفلاین.
- **اندیکاتورهای قطعی** — EMA، RSI، ATR و SMA در پایتون محاسبه و به تفکیک نماد/تایم‌فریم در Parquet ذخیره می‌شوند، پس مدل روی اعداد نهایی استدلال می‌کند نه روی کندل خام.
- **لایه استدلال هوش مصنوعی (Hermes)** — بک‌اند اسکریپت‌شده برای تست و پخش، یا بک‌اند LLM زنده روی `httpx` خام (هر سرور سازگار با OpenAI یا Anthropic) با حلقه فراخوانی ابزار محدود و پیشنهادهای اعتبارسنجی‌شده با اسکیما.
- **موتور ریسک قطعی** — اندازه‌گذاری موقعیت از `EQUITY × RISK_PER_TRADE`، به‌همراه دروازه حداکثر ریسک و حداقل ریسک/ریوارد که در کد نوشته شده و می‌تواند هر پیشنهادی را — فارغ از آنچه AI می‌گوید — رد کند.
- **اجراهای قابل‌ردیابی** — `sync` (شبکه) و `analyze` (آفلاین) دو فرمان جدا هستند، یک زمان‌بند cronمانند روی `schedule.toml` حلقه می‌زند و هر اجرا یک رکورد JSON برای بازبینی می‌نویسد.
- **بریج چارت متاتریدر ۵** — یک سرویس FastAPI که خوانش ساختار بازار ایجنت (اول خطوط روند) را مستقیم روی چارت زنده MT5 رسم می‌کند.

# TradeAgent — ایجنت تحلیل بازار با هوش مصنوعی

> یک ایجنت تحلیل بازار فقط‌خواندنی: تاریخچه کندل‌ها را جمع‌آوری می‌کند، اندیکاتورها را به‌صورت قطعی محاسبه می‌کند و بر اساس یک استراتژی، پیشنهادهای قابل‌ردیابی ورود/خروج/ریسک تولید می‌کند.
>
> **ایجنت می‌تواند بخواند. ایجنت می‌تواند تحلیل کند. ایجنت نمی‌تواند معامله کند.**

---

## دید کلی

TradeAgent یک رکورد محلی و به‌روز از تاریخچه کندل‌ها را برای نمادها و تایم‌فریم‌هایی که استراتژی نیاز دارد نگه می‌دارد و سپس داده‌های ازپیش‌محاسبه‌شده را به لایه استدلال هوش مصنوعی (**Hermes**) می‌سپارد تا استراتژی را ارزیابی کند و معامله پیشنهاد دهد — فقط پیشنهاد، هرگز اجرا.

سیستم **استراتژی‌محور** است: هیچ چیزی در هسته hardcode نشده. یک استراتژی یک پوشه با دو فایل است — `strategy.md` (قواعد، خوانا برای انسان و ایجنت) و `config.py` (نسخه اجرایی: نمادها، تایم‌فریم‌ها، حداقل کندل‌ها، توابع اندیکاتور، پارامترهای ریسک). هسته نمادها و تایم‌فریم‌ها را از کانفیگ می‌خواند، دقیقاً همان‌ها را واکشی می‌کند، اندیکاتورها را در کد محاسبه می‌کند و تنها پس از آن به هوش مصنوعی اجازه استدلال روی اعداد نهایی را می‌دهد. اگر دو فایل با هم ناسازگار باشند، اجرا با صدای بلند شکست می‌خورد تا اینکه تحلیل با نیازمندی‌های گم‌شده ادامه یابد.

## ویژگی‌های کلیدی

1. **قرارداد دوفایلی استراتژی** — قواعد `strategy.md` + نیازمندی‌های اجرایی `config.py`؛ لودر سمت کانفیگ را اعتبارسنجی می‌کند (نمادها، سازگاری تایم‌فریم/حداقل کندل‌ها، یکتایی نام اندیکاتورها) و یک قالب آماده، توافق بین دو فایل را که نویسنده باید حفظ کند به‌وضوح گوشزد می‌کند.
2. **چهار بک‌اند داده بازار** پشت یک رابط `MarketDataProvider` — CCXT (صرافی زنده)، یاهو فاینانس از طریق `yfinance`، ترمینال متاتریدر ۵ (ویندوز) و یک بک‌اند مبتنی بر فایل برای پخش آفلاین. دقیقاً یک ارائه‌دهنده در هر اجرا.
3. **لایه اندیکاتور قطعی** — توابع اندیکاتور (`ema`، `rsi`، `atr`، `sma`، …) که از کتابخانه import می‌شوند و روی هر تایم‌فریم اعلام‌شده اعمال می‌شوند؛ هوش مصنوعی هرگز روی کندل‌های خام محاسبه‌ای انجام نمی‌دهد.
4. **ذخیره‌سازی Parquet به تفکیک تایم‌فریم** — یک فایل مجزا برای هر `(symbol, timeframe)` در `data/market/` شامل کندل‌ها **و** ستون‌های اندیکاتورشان؛ سینک افزایشی، اولویت با سطرهای ذخیره‌شده در برابر تکرارهای مجدد واکشی‌شده، پر کردن شکاف‌ها، اعتبارسنجی تداوم (`ContinuityError` برای حفره ترمیم‌ناپذیر) و هرگز ذخیره کندل ناتمام.
5. **Hermes — لایه استدلال** — بک‌اند اسکریپت‌شده (تست/پخش، بدون کلید API) یا بک‌اند LLM زنده (`TRADEAGENT_LLM_*`، هر سرور سازگار با OpenAI یا Anthropic روی `httpx` خام) با حلقه فراخوانی ابزار محدود، پیشنهادهای ساخت‌یافته و اعتبارسنجی‌شده با اسکیما و حالت تعاملی چندنوبتی.
6. **پیش‌چک‌ها و موتور ریسک قطعی** — وجود داده، بسته بودن کندل‌ها، مقادیر اندیکاتور و حساب R/R *پیش از* فراخوانی ایجنت در کد بررسی می‌شوند؛ اندازه‌گذاری موقعیت از `EQUITY × RISK_PER_TRADE` با دروازه‌های حداکثر ریسک و حداقل ریسک/ریوارد که می‌تواند هر پیشنهادی را — فارغ از آنچه AI بگوید — رد کند.
7. **فضای کاری متعلق به ایجنت** — `data/analysis/<symbol>/` با `registry.md` (سطرهای CANDIDATE / OPEN / CLOSED)، پوشه‌های هر موقعیت (`checklist.md` + تحلیل‌ها) و فایل‌های دانشی که خود ایجنت می‌خواند و می‌نویسد — فقط باز/بسته دستی، هیچ چیزی سفارش اجرا نمی‌کند.
8. **اجراهای تفکیک‌شده + زمان‌بند داخلی** — `sync` (شبکه، فقط جمع‌آوری)، `analyze` (آفلاین، صفر فراخوانی ارائه‌دهنده)، `run` (چرخه ترکیبی) و `scheduler` (حلقه cron-mانند روی `schedule.toml` با احترام به override محدود `set_next_run` خود ایجنت).
9. **مسیر ردیابی کامل** — یک رکورد JSON برای هر اجرا در `data/runs/`: شناسه اجرا، زمان، اسلاگ استراتژی + نسخه، ارجاع اسنپ‌شات، دستورالعمل رندرشده (مسیر، sha256، پرامپت‌ها)، خروجی ایجنت، تصمیم، نتیجه ریسک و بک‌اندی که آن را اجرا کرده است.
10. **chartbridge** — یک بریج FastAPI + ادوایژر متخصص که خوانش ساختار بازار ایجنت (ابتدا خطوط روند) را مستقیماً روی چارت زنده متاتریدر ۵ رسم می‌کند.

## معماری

```text
 استراتژی (دو فایل)
   strategy.md    قواعد و نیازمندی‌ها      (انسان + ایجنت)
   config.py      نیازمندی‌های اجرایی      (تنها چیزی که هسته می‌خواند)
        │
        ▼
 ارائه‌دهنده داده بازار ──────────▶ ذخیره به تفکیک تایم‌فریم
 CCXT · Yahoo · MT5 · file          data/market/<symbol>/<tf>.parquet
        │                                      │
        ▼                                      ▼
 sync    واکشی → حذف کندل در حال شکل‌گیری → پر کردن شکاف
         → بازمحاسبه اندیکاتورها → ذخیره → sync-*.json
        │
        ▼
 analyze (آفلاین، بدون شبکه)
   اسنپ‌شات‌ها + پیش‌چک‌های قطعی ──▶ Hermes
                                      (اسکریپت‌شده | LLM زنده)
                                            │
        NO_TRADE · HOLD · ENTRY_CANDIDATE · EXIT_CANDIDATE
                                            │
                                            ▼
                            موتور ریسک  PASS / REJECT
                                 │
                                 ▼
                  پیشنهاد نهایی + رکورد ممیزی (data/runs/)
                  به‌روزرسانی فضای کاری ایجنت (data/analysis/)
                                 │
                                 ▼
                  اجرا نشده — ایجنت نمی‌تواند معامله کند
```

## شروع سریع

```bash
# نصب (از کد منبع، یک ویل، یا بسته انتشار)
python3 -m venv venv && source venv/bin/activate
pip install .
cp .env.example .env             # کلیدهای LLM، ارائه‌دهنده، مسیرها

# بررسی نصب
tradeagent --help                # sync / analyze / run / scheduler
pytest -q                        # ۹۲۰ تست (هسته + chartbridge)، بدون شبکه

# اجرای ۱ — جمع‌آوری کندل‌ها (شبکه)، سپس اجرای ۲ — تحلیل آفلاین
# با یک ایجنت اسکریپت‌شده: بدون نیاز به کلید LLM
tradeagent sync --strategy price-action --provider yahoo
tradeagent analyze --strategy price-action \
    --scripted '{"XAU/USD": {"decision": "NO_TRADE", "symbol": "XAU/USD", "reasoning": "smoke test"}}'

# سینک ترکیبی → تحلیل، یا زمان‌بند داخلی
tradeagent run --strategy price-action --provider yahoo --scripted '…'
tradeagent scheduler             # حلقه روی schedule.toml (--once = یک گام)
```

استدلال زنده یک سوییچ بدون پرچم است: `--scripted` را حذف کنید و `TRADEAGENT_LLM_*` را در `.env` تنظیم کنید؛ اگر هیچ‌کدام تنظیم نشده باشند، اجرا با کد `2` خارج می‌شود و هر دو گزینه را نام می‌برد. فراخوانی `python -m trading.cli …` همیشه معادل اسکریپت `tradeagent` است.

**chartbridge** (دو ترمینال):

```bash
uvicorn chartbridge.bridge.main:app --host 127.0.0.1 --port 8000
python -m chartbridge.agent.main --backend synthetic
```

**Docker** (بدون پایتون هاست): `docker compose build`، سپس `docker compose run --rm analysis --strategy price-action --scripted '…'` و `docker compose up -d bridge`.

## تست و کیفیت

- **۹۲۰ تست** (هسته + chartbridge) کاملاً آفلاین اجرا می‌شوند — بدون شبکه و بدون کلید LLM: `pytest -q` یا `make test-local`.
- **تست پخش (Replay)** — یک ارائه‌دهنده مبتنی بر فایل، اسنپ‌شات‌های Parquet ذخیره‌شده را سرو می‌کند، بنابراین همان داده بازار + همان استراتژی همیشه همان لایه‌های قطعی را بازتولید می‌کند.
- **Lint و CI** — `make lint` (ruff) و GitHub Actions در هر push/PR روی پایتون ۳.۱۲ ruff + pytest را اجرا می‌کنند.
- **شکست بلند (Fail loud)** — ناسازگاری کانفیگ، داده ناقص، خروجی نامعتبر ایجنت و خطاهای ارائه‌دهنده، اجرا را متوقف می‌کنند به‌جای اینکه بی‌صدا افت کیفیت بدهند.
- **انضباط انتشار** — SemVer 2.0.0 در `VERSION`، Keep a Changelog 1.1.0 در `CHANGELOG.md`، Conventional Commits، و اجباری‌شده توسط تست‌های نسخه‌بندی در مجموعه تست عادی.

## وضعیت

نسخه فعلی **1.12.0** — فازهای هسته A تا G تحویل شده‌اند: ذخیره‌سازی به تفکیک تایم‌فریم و تداوم، پیش‌چک‌های قطعی، حلقه ایجنت و موتور ریسک، فضای کاری متعلق به ایجنت، تست پخش آفلاین، تفکیک sync/analyze/scheduler و بک‌اند LLM زنده.
